# 🌉 Мостики к стоковому контенту — Azeroth: Эхо Пустоты

> Документ описывает, как кастомный контент реалма вплетён в стоковый
> мир WoW 3.3.5a так, чтобы взаимодействие с расами, квестами, инстансами
> и механиками выглядело органично, а не «пришито сбоку».

---

## 1. Сюжетный мостик: канон → альтернативная линия

Стоковый финал WotLK (падение Короля-лича, патч 3.3.5a) является **точкой
расхождения**. Все стоковые события до него — канон реалма:

| Стоковое событие | Мостик в «Эхо Пустоты» |
|---|---|
| Падение Артаса (Icecrown Citadel) | Осколок трона падает в Драконий Погост — **там же, где стоковый Ан'кахет и галактическая аномалия Ноктис** (регион уже «аномальный» в каноне) |
| Даларан (стоковый город-хаб) | Штаб Ордена Рассвета в Серебряном анклаве — **рядом со стоковым Серебряным турниром**, кастомные НПС стоят на площадке, не ломая стоковую застройку |
| Рыцари Смерти (DK-стартовая) | Лор-реплика класса DK в реестре: «Пустота помнит твой долг Фродмурским шёпотом» — связывает Эхо со стоковой историей Овены |
| Драконьи полёты (стоковые Союз Пяти знамён) | Стражи Пустоты — «внепартийный» совет драконов, лорно допустимый: драконы уже объединялись против Нелтариона |
| Йогг-Сарон (Ulduar) | Усмешка Бездны — «осколок сознания», модель Йогг-Сарона (28865) — визуальный мостик: игрок узнаёт «черты» знакомого Старого Бога |

## 2. Расовый мостик

Каждая из 10 рас получает персональную реплику Ордена при входе и у
Портального Стража (реестр `race_greetings`), лорно связанную со стоковой
историей расы:

| Раса | Мостик к стоковому лору |
|------|------------------------|
| Люди | «Строите ордена» — отсылка к Серебряному Рассвету и Алому натиску |
| Орки | «Ярость против своих» — последствия стоковых событий Громового Утёса |
| Дворфы | «Камень не слышит шёпота» — дворфийская устойчивость к Титаническим влияниям (Ulduar) |
| Ночные эльфы | «Эльюны ведали Пустоту» — мостик к стоковой истории Эльюны и Кель'таса |
| Нежить | «Быть чужой куклой» — мостик к Проклятию Разума (Скальд) |
| Таурены | «Земля-Мать дрожит» — стоковая боль Мулнора после Нордскола |
| Гномы | Инженерия против магии — мостик к Гномурегену |
| Тролли | «Лоа шепчут» — мостик к Зул'Драку и Зул'Джину |
| Эльфы крови | «Жажда магии» — мостик к Солнечному Колодцу и «зависимости» |
| Драэней | «Бежали от Пустоты» — прямая связь с каноном: эредары и Кил'джеден |

**Фракционный выбор в К3 (Альянс/Орда)** использует стоковые точки сбора
знамён в Драконьем Погосте — игроки узнают «военные лагеря» стокового
запада Нордскола.

## 3. Квест-мостик (интеграция через quest_template)

Портальный Страж (70001) — точка входа. Для интеграции со стоковой
квест-системой зарезервированы **ID квестов 70001–70099** (конвенция в
`sql/README.md`). Планируемые мостики:

| Квест | ID | Стоковый мостик |
|-------|-----|----------------|
| «Шёпот осколка» | 70001 | Выдаёт Портальный Страж в Штормграде/Оргриммаре; требование: завершить стоковую цепочку «Падение Короля-лича» (или 80 ур.) |
| «Доклад Элианне» | 70002 | Передаёт игрока кастомному НПС 70120 в Даларане; награда — доступ к К1 |
| «Знамёна над Погостом» | 70003 | Фракционный мостик К3: награда = +репутация стоковому «Союзу Пяти знамён» (идентификатор 1106) |

Реализация квестов — через ALE (`RegisterQuestEvent`) или `quest_template`
(миграция 0014, в планах roadmap). Текущая реализация кампаний через
таблицу `realm_campaign_progress` дублирует механику квестов, но не
ломает стоковую панель квестов игрока.

## 4. Мостик к инстансам и рейдам

| Стоковый инстанс | Связь с Эхом Пустоты |
|------------------|---------------------|
| **Icecrown Citadel** | Лорно «до» Эха: осколок Трона — остаток трона из ЛК. В кампании 1 встречаются «остатки гарнизона ЛК» (стоковые модели) |
| **Ulduar** | Йогг-Сарон = визуальный прототип Усмешки (модель 28865); «правило: Старые Боги спят» — цитата лора Ulduar |
| **Нокс** (Naxxramas) | Культисты Культа используют стоковые модели культистов Нокса (28513) — игроки «узнают» стиль |
| **Ониксия/ONY** | Сквернозор (70140) — модель чёрного дракона (26446), мостик к стоковым Стражам чёрного полёта |
| **ДК-стартовая зона** | Лор: часть Пустотников — «иссушенные» рыцари Смерти, не оправившиеся от падения Артаса |

**Баланс (echo-balance)**: WorldDamageScalar применяется и к стоковым
мобам, и к кастомным — сложность мира настраивается единообразно,
без «дискотеки сложности» между стоком и кастомом.

## 5. Мостик к механикам стокового мира

| Механика | Как используется |
|----------|------------------|
| **PvP-зоны** | PvP-зона реалма — стоковый Драконий Погост (zone 4080), где уже есть стоковые World PvP-объекты (Битва за Скалу Затмений) |
| **Репутации** | Жетоны Эха не заменяют стоковые репутации; награды кампаний дают **доп. жетоны**, а не репу — стоковые фракции не обесцениваются |
| **Профессии** | Расходники PvP-шопа (рунные зелья, флаконы) = стоковые item_id — игроки-алхимики не теряют рынок |
| **Таланты/спеллы** | Никаких изменений в стоковых классах; «магии слабеют у разлома» реализовано аурой 33757 (стоковый дебафф), а не правкой ядра |
| **Маунты** | «Бездна-Пегас» (70003) — стоковая модель крылатого коня (6449) в теневом перекрасе через displayid — не требует custom DBC до фазы релиза |
| **Почта** | Все награды кампаний идут через стоковую почту (`SendMail`) — привычный UX |

## 6. Визуальные мостики

1. **Модели НПС** — все 19 кастомных отображений взяты из стокового клиента
   3.3.5a (`creature_template_model`, миграция 0008/0012): игроки не видят
   «пустых» моделей и NPC-болванок.
2. **Цвета чата** — кастомные сообщения используют схему, схожую со стоковыми
   системными каналами (фиолетовый Пустоты близок к цвету epic-лута).
3. **Панель аддона** — шрифты и рамки стандартные 3.3.5a (`GameFontNormal`,
   `UIPanelButtonTemplate`, `CharacterFrameTabButtonTemplate`) — аддон
   выглядит «родным» для клиента.
4. **Телепорты** — все точки телепорта (Страж, кампании) — стоковые
   координаты (Даларан, Штормград, Оргриммар) — не «висят в воздухе».

## 7. Технические гарантии интеграции

| Гарантия | Реализация |
|----------|-----------|
| Не ломать стоковые квесты | Кастомные ID (70000+) не пересекаются со стоковыми; спавны НПС — с новыми guid (7000000+) |
| Не ломать стоковый loot | Стоковые item_template не изменяются — только INSERT новых 70000+ |
| Обратная совместимость БД | Все миграции идемпотентны (DELETE+INSERT), можно перезапускать |
| Единый баланс | echo-balance масштабирует и сток, и кастом одинаково |
| Кириллица | SET NAMES utf8mb4 во всех миграциях; ядро AC хранит UTF-8 нативно |

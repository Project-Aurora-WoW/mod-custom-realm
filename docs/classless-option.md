# 🌌 Опция «Classless»: Пустота дробит классы

> Тех-документ будущей арки кампании 5. Референс реализации:
> [azerothcore-wotlk-classless](https://sourcecraft.dev/m-orlovrus59/azerothcore-wotlk-classless)
> (форк ядра: mod-classless `f841161`, класс Hero, мобильный кастинг).
> **Сейчас НЕ включено** — см. [`../modules/README.md`](../modules/README.md).

---

## 1. Лор-обоснование

Из [`lore/universe.md`](lore/universe.md): развеянная в кампании 3 Усмешка
Бездны *дробится* — и её осколки продолжают работу. В арке 4 Архонт
Нехал'тхар собирал осколки для повторной сборки. Арка 5: даже рассеянная,
Усмешка достигает самого фундамента мира — **того, что делает воина воином,
а мага магом**.

Ключевая идея арки: *«Классы — это узор, наложенный на хаос. Усмешка
стирает узор»*.

| Механика | Лор-подача |
|----------|-----------|
| Границы классов размываются (classless) | Осколки Усмешки «переписывают» клятвы, данные классовыми мастерами: талант-деревья становятся открытыми |
| Класс Hero (CLASS_HERO=10) | «Безмолвный» — тот, кто слушал шёпот слишком долго и перестал быть собой; новая, десятая сущность |
| Мобильный кастинг (cast on move) | «Шёпот не ждёт» — пустотные техники не требуют остановки |
| Открытые классовые умения | «Культ дарит покой. Пустота дарит вечность... и всё, что было чужим» |

Драматургия: игрок **проходит через дробление** как часть сюжета
(временный classless-режим в финальных главах арки 5) — либо мир
переходит в classless навсегда (отдельное решение запуска).

## 3. Условия включения (чек-лист решения)

Включение classless допустимо только при выполнении **всех** пунктов:

1. [ ] Тестовый реалм развёрнут, базовая регрессия кампаний 1–4 пройдена
      (`testing-plan.md`, разделы 1–7)
2. [ ] Решение по лору принято: временный режим (арка 5, главы) или постоянный
3. [ ] Баланс-контур перепроверен: echo-balance/echo-pve/echo-pvp против
      classless-хуков урона (профили Hero, альтернативные реакции)
4. [ ] Классовые реплики (`class_greetings`) и расовые (`race_greetings`)
      пересмотрены: для Hero нужны новые реплики в реестре
5. [ ] Гейты кампаний: `min_level` остаётся, но классовые механики глав
      (например, ветка Альянс/Орда) валидны для classless-персонажей
6. [x] Движок: mod-ale принят (миграция с mod-eluna завершена, ALE+Eluna
      смешивать не требуется), тест всех Lua-скриптов на тестовом реалме
7. [ ] Клиент: проверка отображения CLASS_HERO в клиенте 3.3.5a
      (ChrClasses.dbc — может потребоваться патч, см. client-patch.md ч. 4c)
8. [ ] Гилдии/трансмог: класс-зависимые проверки в модулях не ломаются

## 4. Эталонная схема DBC (уже доступна)

В референс-ядре полная база `data/sql/base/db_world/` (~400 таблиц),
включая `spell_dbc.sql`, `chartitles_dbc.sql`, `chrclasses_dbc.sql` —
**это эталон структуры для наших будущих DBC-миграций** (см. `../sql/README.md`).
Использовать при создании `spell_dbc`-записей аур Пустоты и Hero-контента.

## 5. Откат

Classless включается config-флагами и пином ядра. Откат: возврат на
`azerothcore-wotlk` (наше зеркало) + пересборка + `.reload config`.
Персонажи, обучившие чужие классовые спеллы, чистятся скриптом
(референс: waloriaold `removespellcommand.lua` — кампенсация томами).

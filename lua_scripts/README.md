# 🧩 Lua-скрипты — Azeroth: Эхо Пустоты

> Серверные Lua-скрипты для движка **ALE (mod-ale, AzerothCore Lua Engine)** —
> форка [Eluna](https://github.com/ElunaLuaEngine/Eluna) с расширенным API
> для AzerothCore (см. [`../modules/README.md`](../modules/README.md)).
> Все скрипты используют единую лор-цветовую схему:
> Пустота `|cff8e44ad`, Орден Рассвета `|cff5dade2`, Культ `|cffc0392b`.
>
> **Порядок загрузки ALE**: файлы `*.ext` грузятся **до** всех `*.lua`
> (независимо от имён), сами `.lua` — не гарантированно по алфавиту.
> Поэтому `.ext` — это реестр кампаний `00_CampaignRegistry.ext`
> (гарантированно первым) и служебные расширения AIO-стека
> (`_Misc.ext`, `StackTracePlus.ext`), все остальные скрипты — `.lua`.
> Скрипты не зависят от
> алфавитного порядка среди `.lua`: каждый берёт константы из глобальной
> таблицы `AzerothEchoCampaigns`, а события регистрирует независимо.
> Быстрая перезагрузка скриптов (dev): `.reload ale`.

### Архитектура реестра

Скрипты кампаний (`Campaign1/2/3.lua`, `AddonBridge.lua`) **не дублируют** константы,
а берут их из глобальной таблицы `AzerothEchoCampaigns` (00_CampaignRegistry.lua):

```lua
local REG = AzerothEchoCampaigns
local TAG = REG.meta.tag                    -- тег чата
local CAMPAIGN = REG.campaigns[1]           -- кампания 1
local NPC_ARCHMAGE = CAMPAIGN.npc.archmage  -- entry НПС
local REWARD_ITEM = CAMPAIGN.rewards.token  -- entry награды
local DB_TABLE = REG.meta.db_table          -- таблица прогресса
```

Добавление новой кампании = добавить запись в реестр + новый скрипт кампании.
Порядок загрузки критичен: расширение `.ext` гарантирует, что реестр
доступен остальным скриптам (ALE грузит `.ext` до всех `.lua`).

Фактический порядок загрузки (ALE):

```
00_CampaignRegistry.ext  → реестр кампаний и баланс (первым, .ext)
extensions/_Misc.ext + StackTracePlus.ext        → .ext: randomseed + traceback (до всех .lua)
05_VoidAuras.lua         → ауры Пустоты (зависит от реестра)
06_WaloriaRewards.lua    → награды за уровни (Waloria-подход)
07_StartingZone.lua      → выбор стартовой зоны (НПС 70001)
08_ClientFixes.lua       → клиентские фиксы + лор-анонсы
09_WorldChat.lua         → мировой чат (.chat on/off)
10_EventSystem.lua / 11_FixGear.lua / 12_ZoneRestrictor.lua / 20_PvpSystem.lua / 30_PvpShop.lua
13_AccountMounts.lua / 14_AutoLearnSkills.lua   → Tier A (eluna-scripts)
15_Enchanter.lua / 16_GoldStorage.lua           → НПС-сервисы (eluna-scripts)
17_TimeRift.lua / 18_VoidCorruption.lua         → «Разломы»/«Порча» (eluna-scripts)
19_PlayedTimeRewards.lua                        → награды за наигранное время (public-scripts)
AIO.lua + queue.lua + Dep_*/lualzw-zeros (deps)  → AIO-стек (Rochet2/AIO v1.74, dwrath-eluna-3-3-5a)
Store_DataStruct.lua → Store_Server.lua → Store_Client.lua → AIO-магазин
21_FactionChanger.lua / 22_SanctuaryPvP.lua     → перемена фракции / убежища-FFA (public-scripts)
23_WeaponMaster.lua / 24_Lottery.lua / 25_SkipDkStarter.lua / 26_PrayerAltar.lua → Tier B (0024)
27_Classless.lua                                → Classless-арка К5 (0025)
28_RandomEnchant.lua                            → random-энчанты оружия (0028)
```

Порядок среди `.lua`-файлов показан для чтения; ALE не гарантирует
алфавитность, поэтому скрипты друг от друга не зависят — только от
реестра `.ext`.

C++-модули ядра (echo-balance, echo-campaigns) инициализируются до Lua-скриптов ALE.

### 00_CampaignRegistry.ext — реестр кампаний

### 05_VoidAuras.lua — ауры Пустоты «Эхо Шёпота»

Скриптовая система поверх стокового дебаффа `REG.meta.whisper_aura` (33757):
стоковый спелл даёт визуал, балансная логика — в Lua, параметры — в реестре
(`REG.void_aura`):

| Параметр | По умолчанию | Смысл |
|----------|--------------|-------|
| `stack_interval_secs` | 45 | секунд у разлома до +1 стака |
| `whisper_interval_secs` | 30 | частота шёпота (сек) |
| `max_stacks` | 6 | порог «коллапса рассудка» |
| `rift_radius` | 60 | радиус действия разлома (ярдов) |
| `sanity_damage_pct` | 0.5 | % макс. HP за тик шёпота за стак |
| `collapse_damage_pct` | 5 | % макс. HP при коллапсе |

Механика:
- вход в Драконий Погост → стоковый дебафф + сброс стаков + старт тиков;
- каждые 45 сек у разлома: +1 стак (до 6); на 6-м — «коллапс рассудка»
  (урон 5% max HP, предупреждение, сброс стаков);
- каждые 30 сек: случайная лор-реплика разлома (7 вариантов) + урон
  0.5% × число стаков;
- выход из зоны → снятие ауры, сброс стаков, отмена тиков.

Локализация: у игроков с ruRU-клиентом (DbcLocale 8) все реплики на русском,
у остальных — на английском. Наборы строк — в таблице `L` модуля.

## CampaignManager.lua — служебный модуль управления кампаниями

Центральная точка жизненного цикла кампаний. Другие скрипты могут
использовать API вместо прямых SQL-запросов:

```lua
local M = AzerothEchoManager
M.GetProgress(player, campId)          -- -> chapter, completed, data
M.SetChapter(player, campId, ch, done) -- сохранить главу
M.ResetCampaign(player, campId)        -- полный сброс
M.CanStart(player, campId)             -- гейт: уровень + токен -> ok, why
M.CompleteCampaign(player, campId)     -- финал: награды + журнал + мир
M.GrantTokens(player, n, reason)       -- выдать Жетоны Эха
M.GrantCampaignRewards(player, campId) -- предметы реестра почтой + жетоны
M.LogAction(guid, campId, ch, action, detail) -- журнал realm_campaign_log
```

## 09_WorldChat.lua — мировой чат

  (`REG.worldchat`, `00_CampaignRegistry.lua`).

Исправления относительно оригинала:

## 27_Classless.lua — Classless-арка К5

Минимальный порт [Shikifuyin/AzerothCore-ClassLess-Solo](https://github.com/Shikifuyin/AzerothCore-ClassLess-Solo)
на ALE **без AIO-клиентского UI** (конвенция «минимальной версии», см. задачу 6).

Лор-подача: «Классы — это узор, наложенный на хаос. Усмешка стирает узор» —
в финальных главах арки К5 рассеянная Усмешка Бездны «переписывает» классовые
клятвы, и персонажи могут учить умения чужих классов.

- **Механика**: у каждого персонажа очки спеллов (= уровень) и слоты глифов;
  `learn/unlearn` изучает «чужой» классовый спелл или глиф. Ранги чужих спеллов
  автоподстраиваются под уровень (логика референса `UpdateAllSpellsRanks`).
- **Управление** — чат-команда `.aeclassless help|status|list|learn <id>|unlearn <id>|reset`
  (замена AIO-хендлеров `CommitAbilities`/`ResetAbilities` референса).
- **Таблица**: `character_classless` (0025, **acore_characters**); DDL в скрипте
  не создаётся (конвенция реалма — таблицы только миграциями); `pcall`-guard
  отключает систему, если таблица не применена.
- **Объём (минимальная версия)**: портируются **спеллы + глифы** чужих классов.
  **Таланты НЕ включены**: данные талантов референса (`CLDataTalents.lua`, ~2400
  строк) завязаны на C++-класс талант-дескрипторов, требование-дерево и
  пет-таланты, которые в Eluna/ALE ненадёжно снимаются через `RemoveSpell` —
  полный перенос не гарантирует корректного unlearn (риск «залипших» талантов).
  Запасные/faction-спеллы референса исключены.
- **Служебное**: для глифов/спеллов родного класса возвращается подсказка
  «изучай через тренера» (аналог AIO-валидации референса в минимальной версии).

## Установка

1. Убедиться, что установлен **mod-ale** (см. [`../modules/README.md`](../modules/README.md)).
2. Применить SQL-миграции (см. [`../sql/README.md`](../sql/README.md)) —
   скрипты зависят от НПС 70001, 70100, 70110, 70120 и item 70001.
3. Скопировать `00_CampaignRegistry.ext` и все `*.lua` в каталог
   `lua_scripts/` сервера (рядом с `worldserver`).
4. Перезапустить `worldserver` (или `.reload ale` — только для разработки).
5. Проверить в логе:
   ```
   [EchoOfTheVoid] 00_CampaignRegistry.ext загружен (реестр кампаний: 4 кампании).
   [EchoOfTheVoid] WelcomeSystem.lua загружен.
   [EchoOfTheVoid] PortalGuardian.lua загружен (НПС 70001).
   [EchoOfTheVoid] Campaign1.lua загружен (НПС 70100/70110/70120).
   ```

## Конвенции разработки

- Каждая глава кампании — отдельная функция-хендлер; завершение главы
  инкрементирует `chapter` в `realm_campaign_progress`.
- Завершение кампании: `completed = 1`, награда — через `SendMail`.
- Общие константы (TAG, цвета, entry НПС/предметов, имя таблицы БД) —
  **только в `00_CampaignRegistry.lua`**; в скриптах кампаний объявлять
  дубликаты запрещено.
- Зарезервированные entry: НПС 70001–79999, предметы 70001–79999.

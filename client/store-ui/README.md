# 🛍️ Клиентская часть AIO Store System (Магазин)

> Источник: `eluna-aio-storesystem` (AIO Store System, авторы Vlad/Test).
> Содержимое этого каталога включается в `patch-x.mpq` при сборке
> (см. `../docs/client-patch.md` ч. 7). Без клиентской части кнопка
> «Магазин» не появится и UI не откроется.

## Что входит

| Файл (из референса `Client/Interface/Store_UI/`) | Назначение |
|---------------------------------------------------|-----------|
| `Frames/StoreFrame_Main.blp` | Все текстуры UI магазина (рамка, кнопки, баннеры) — один атлас 1024×1024 |
| `Currencies/Gold.blp` | Иконка валюты «Золото» |
| `Currencies/Token.blp` | Иконка валюты «Жетон Эха» |

## Структура в MPQ (patch-x)

```
Interface/
└── Store_UI/
    ├── Frames/StoreFrame_Main.blp
    └── Currencies/
        ├── Gold.blp
        └── Token.blp
```

## Ещё обязательные компоненты клиента

1. **AIO-клиент** (`Interface/AddOns/AIO/`) — фреймворк обмена
   сообщениями клиент↔сервер, необходим и для магазина, и для будущих
   AIO-систем (SpellAIO и др.). Берётся из репозитория
   [ShinoShin/AIO](https://github.com/ShinoShin/AIO)-совместимой сборки —
   клиентская часть добавляется в аддоны патча, серверная (`AIO_Server.lua`)
   кладётся в `lua_scripts/` сервера.
2. **Серверные скрипты магазина уже в репозитории**: `Store_Server.lua`,
   `Store_DataStruct.lua` копируются в `lua_scripts/` автоматически
   (`setup-build.sh`); `Store_Client.lua` — это серверная сторона
   клиентского кода (AIO отдаёт её клиенту при загрузке, отдельного
   аддона магазина не требуется).

## Процедура

1. Скачать 3 BLP-файла из каталога `Client/Interface/Store_UI/`
   репозитория `eluna-aio-storesystem`.
2. Разложить по структуре выше в каталоге сборки MPQ (вместе с DBC
   из ч. 1–4 и аддоном AIO).
3. Перепаковать `patch-x.mpq`, пересчитать SHA256 в `manifest.json`
   (процедура — `../client/README.md`).
4. В игре: Escape → «Магазин».

⚠️ BLP-файлы бинарные — через репозиторий реалма не переносятся,
берутся напрямую из референса (аналогично patch-Z из custom-maps).

## Локализация

Тексты UI (заголовок «Магазин», кнопка «Купить!», подтверждение
покупки) уже локализованы в `Store_Client.lua` (сервер отдаёт клиенту).
Названия категорий/услуг — в `realm_store_categories` /
`realm_store_services` (миграция `0020_store_system.sql`).

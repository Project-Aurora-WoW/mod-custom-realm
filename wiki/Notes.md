## 1. Известные проблемы при развёртывании

- **Зафиксированные версии.** Ядро собирается на коммите `1459af95…`; `mod-ale`
  должен соответствовать этой ревизии (ALE использует внутренние API ядра).
  По умолчанию в гайдах указан коммит `84b85cc5…` — сверяйте с релизом.
- **Расхождение CharDB/WorldDB в `0002`.** Миграция `0002_campaign_progress.sql`
  создаёт `realm_campaign_progress`. Скрипты кампаний читают её через
  `CharDBQuery` (characters). Рекомендуемый вариант — применить `0002` в
  `acore_characters` (вариант A), либо заменить в `Campaign1/2/3.lua`
  `CharDBQuery` → `WorldDBQuery` (вариант B). См. `docs/deployment.md` шаг 8.
- **Координаты спавнов** Драконьего Погоста и Зул'Драка приблизительны —
  требуют выверки на тестовом реалме.
- **Титул 48 (TitleMask)** — эмпирический; обязательная проверка на клиенте.
- **`patch-x.mpq`** содержит клиентские правки; `Map.dbc` в него включать нельзя
  (только в `patch-Z.mpq`). Титул/маунт требуют отдельного DBC-патча
  (`docs/client-patch.md`).
- **AIO-отладка.** Если `AIO_CODE_OBFUSCATE = true` в `AIO.lua`, клиентский код
  минифицируется — строки в трейсбеках ломаются. При отладке ставьте `false`.

## 2. Безопасность

- Не используйте пароль `root` в проде; создайте отдельного пользователя БД.
- Lua-запросы к БД не параметризуются в ALE — экранируйте строки хелпером
  `REG.escape` (введён для имен/текста).

## 3. Запуск CI

- Для релиза нужен `contents: write` у `GITHUB_TOKEN` (см. `CI-Build.md`).
- Windows-сборка качает Boost (~200 МБ) и MySQL (~50 МБ) с сети — при недоступности
  этих сайтов в вашем регионе может потребоваться VPN или зеркала.

## 4. Совместимость

- Клиент строго **3.3.5a (build 12340)**.
- Максимальный уровень — **80** (концепция реалма). Аддоны и упоминания 255
  уровня из dWrath не применяются.
